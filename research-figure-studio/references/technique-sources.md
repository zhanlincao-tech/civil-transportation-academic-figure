## Reusing an external recipe later

1. Start from the scientific question, dataset and accepted current version. A minor revision stays on that version.
2. Inspect the actual preview and source when a specialist recipe adds a needed capability; record the local source/recipe and necessary adaptations in the task output.
3. Retain relevant layout ideas while replacing demo evidence completely and applying the confirmed personal style. Do not import small fonts, dark palettes, removed frames, automatic fits/tests or decorative arrows.
4. Check the actual output in the requested format and viewing size. Use source code and structural inspection as evidence alongside visual review, never as a substitute.

Exact statistical methods, smoothing, hypothesis tests and model explanations require appropriate scientific inputs; this borrowing process does not authorise inventing them or running unrelated analyses. Another skill's mandatory questionnaires or service calls are not copied into this workflow.
