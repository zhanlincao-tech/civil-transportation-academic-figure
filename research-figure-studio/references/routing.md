# Figure routing

Choose from the scientific question and evidence, not from a favorite template.

| Evidence / question | Preferred form | Avoid |
|---|---|---|
| Explain a hypothesis, mechanism, or causal chain | Concept/mechanism diagram | Decorative illustration, unexplained icons |
| Show a physical setup or engineering structure | Plan/section/detail schematic | Perspective views that hide geometry |
| Compare category magnitudes | Dot or bar plot with honest uncertainty/raw points | 3D bars, unlabeled error bars |
| Show change over ordered x or time | Line/curve plot with symbols where observations exist | Connecting unordered categories |
| Compare two values for each matched object | Paired dot plot with one connector per object | Linking unmatched observations |
| Show relation between two continuous variables | Scatter + justified fit/interval | A line implying order when none exists |
| Show distributions | Box/violin/density plus raw points when feasible | Mean-only bars for small n |
| Show matrix structure | Heatmap with perceptual color scale | Rainbow/jet and missing colorbar |
| Show a scalar field or spatial pattern | Contour/map with coordinates, units, colorbar | 3D surface used only for decoration |
| Show effect and uncertainty | Forest/interval plot | Asterisks without effect size/context |
| Show modeled exceedance versus intensity | Probability curves with defined events, conditions and model | Treating modeled quantiles as samples or confidence bounds |
| Show connectivity and direction | Node–edge diagram with explicit edge directions and weight key | Mapping schematic positions as geographic coordinates |
| Show changing frequency content | Aligned time trace and time–frequency plot | Unlabeled spectral scale or unexplained window and display limits |
| Combine mechanism and validation | Schematic-led composite | Equal-sized filler panels |

Use a multi-panel figure only when each panel contributes unique evidence to the same conclusion.

When expanding a sample library, list the research questions covered by the existing examples and select additions for gaps in evidence types. Treat visual variants of one plot as alternatives within a family. Label candidate layouts as candidates until selected.
